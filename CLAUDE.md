# Правила работы в этом репозитории

Семейный дневник жизни новорождённого: голос через Алису → сервер → разбор
моделью → дашборд на телевизоре, админка и PWA на телефоне. Контракт —
`docs/CONTRACT.md`, он источник правды по схеме, API и договорённостям.

## Браузер и dev-серверы

**Открывай только `http://localhost:<порт>`.** Vite печатает два адреса, Local и
Network (`host: true` нужен, чтобы заказчик открывал админку с телефона). Если
взять сетевой — `http://192.168.x.x:5174` — заказчику выскакивает запрос
разрешения **на каждое действие** браузера. Local такого не требует.

Порты: админка 5174, дашборд 5173, сервер 8787.

  открывать на запись, не пересоздавать, не «чинить». Эксперименты — на

  Проверка здоровья идёт по `/healthz`, при неудаче откат на прежнюю ревизию.

## Авторизация устройств

Дверь — один хук `onRequest` в `apps/server/src/auth-guard.ts`; открыты только
`/healthz`, `/pair`, эндпоинты сопряжения и оформление PWA (поимённо, не
префиксом). Вебхук Алисы к этой схеме не относится.

На сервере есть короткая команда: `bt pending`, `bt approve КОД`, `bt list`,
`bt revoke <id>`, `bt issue`. Одиночным ssh — `ssh host '$HOME/.local/bin/bt list'`
(профиль в неинтерактивном shell не читается). Сессию, выпущенную для разовой
задачи, после неё **отзывать**.

## Данные и честность

Проект трижды получал на проде правдоподобную неправду, поэтому правило жёсткое:
**«не было» и «не записали» — разные вещи**, и число, которого мы не заработали,
показывать нельзя. Среднее не делится на сутки, когда дневник не вели; значение
между нулём и единицей не округляется в «0»; допущение модели помечается `[?]`.

«Сводка» сделана для врача: она **показывает факты и не выносит суждений** —
никаких «норма», «мало», «всё хорошо» и оценочных цветов. Оценивает врач.

## Таксономия

подписи у каждого свои, но расхождение состава ломает `pnpm typecheck`. Раньше
копий было три и они молча расходились.
