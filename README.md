# BabyTracker

Голосовой трекер жизни ребёнка. Говоришь Яндекс-станции «Андрей заснул» — событие
попадает на сервер, а на телевизоре обновляется sci-fi дашборд.

```
  голос              ≤3 сек                    публичный HTTPS
┌────────────┐   ┌──────────────┐   ┌────────────────────┐   ┌──────────────────────────┐
│ Станция    │──▶│ Яндекс       │──▶│ Cloudflare Tunnel  │──▶│  Fastify  :8787          │
│ с Алисой   │   │ Диалоги      │   │ (VM за NAT)        │   │  POST /alice/<secret>    │
└────────────┘   └──────────────┘   └────────────────────┘   └───────────┬──────────────┘
                                                                         │
                    ┌────────────────────────────────────────────────────┼───────────────┐
                    ▼ синхронно, <200 мс                                 ▼ в очередь     ▼
            ┌──────────────────┐                            ┌────────────────────┐   ┌───────┐
            │ fast-path матчер │                            │ worker: claude -p  │   │  SSE  │
            │ «заснул/проснулся│                            │  + MCP-тулы        │   └───┬───┘
            │ → ответ голосом  │                            │  2–15 сек          │       │
            └────────┬─────────┘                            └─────────┬──────────┘       │
                     │                                                │                  ▼
                     └────────────────▶ SQLite ◀──────────────────────┘         ┌─────────────────┐
                                                                                 │ дашборд на TV   │
                                                                                 └─────────────────┘
```

**Почему два контура.** Алиса обрывает вебхук через 3 секунды, а `claude -p` реально
отвечает 2–15. Поэтому детерминированный матчер отвечает голосом мгновенно, а Claude CLI
разбирает фразу следом и правит данные через узкий набор MCP-тулов. Если CLI не установлен
или не авторизован — сервер продолжает работать, просто без умного разбора.

## Состав

| Каталог | Что это |
|---------|---------|
| `apps/server` | Fastify: вебхук Алисы, REST, SSE, fast-path, worker, MCP-сервер |
| `apps/dashboard` | React + Vite, sci-fi дашборд для экрана 1920×1080 |
| `apps/tv` | Тонкая Android TV обёртка WebView (Kotlin) |
| `infra` | Подготовка VM, systemd-юниты, деплой, туннель |
| `docs` | Контракт, подключение Алисы, развёртывание |

## Локальный запуск

```bash
pnpm install
cp .env.example .env && openssl rand -hex 16   # положить в ALICE_WEBHOOK_SECRET
pnpm dev                                        # server :8787 + dashboard :5173
```

## Что умеет сейчас

MVP заточен под **сон**: «заснул» открывает событие, «проснулся» закрывает, дашборд считает
суммарный сон за сутки, число засыпаний и рисует 24-часовую ленту.

Схема БД и MCP-тулы **уже принимают** кормление, подгузники, измерения и лекарства — расширение
не потребует миграций, нужно только дополнить словарь fast-path и промпт.

## Стек и почему он такой

- **TypeScript + Fastify 5** — один язык на сервере и во фронте, быстрый роутер: вебхуку
  критична задержка.
- **SQLite через встроенный `node:sqlite`** — данных мало (десятки событий в день), а на VM
  нет тулчейна собрать нативный `better-sqlite3`. Требует Node ≥ 24.
- **SSE, не WebSocket** — поток односторонний, `EventSource` сам переподключается,
  что важно для телевизора с нестабильным Wi-Fi.
- **WebView вместо нативного TV-приложения** — дашборд пишется один раз, обновляется
  деплоем сервера, а не переустановкой APK.
